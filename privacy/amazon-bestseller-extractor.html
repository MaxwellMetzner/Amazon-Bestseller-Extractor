Amazon BSR Extractor Privacy Policy

Effective date: May 27, 2026

Overview

Amazon BSR Extractor is a Chrome extension that helps users view Best Sellers Rank information on supported Amazon product pages. The extension reads Best Sellers Rank text and category links that are already present on the currently open Amazon product page and displays the detected information in the extension badge and popup.

Data Collection

Amazon BSR Extractor does not collect, transmit, sell, or share user data.

The extension does not collect personal information, names, email addresses, account identifiers, credentials, payment information, form inputs, browsing history, analytics data, or advertising data.

Page Access

The extension runs only on supported Amazon storefront pages. It processes product pages locally in the browser to detect Best Sellers Rank information already visible in the page content.

The extension does not read unrelated websites, checkout pages, payment information, passwords, private messages, or non-Amazon browsing activity.

Data Storage

Amazon BSR Extractor does not store extracted rank data on an external server. Rank information is used locally for the extension badge and popup display.

Data Sharing

Amazon BSR Extractor does not sell, rent, transfer, or share user data with third parties.

Remote Code

Amazon BSR Extractor does not execute remote code. All extension JavaScript is included in the submitted extension package. The extension does not load, import, evaluate, or execute remotely hosted scripts.

Permissions

Amazon BSR Extractor uses limited access to supported Amazon storefront domains so it can read Best Sellers Rank information from the currently open Amazon product page. The extension also uses declarative browser behavior to keep the extension action limited to relevant supported pages.

Changes to This Policy

This privacy policy may be updated if the extension's functionality or data practices change. Updates will be published on this page.

Contact

For questions about this privacy policy, contact the developer through the project repository: https://github.com/MaxwellMetzner/Amazon-Bestseller-Extractor
